# Personnaliser une organisation

Les **administrateurs** d'une organisation peuvent en modifier les informations et
l'apparence. Les administrateurs de l'**organisation parente** et les super-administrateurs
le peuvent également.

## Modifier les informations

Sur la page de l'organisation, cliquez sur **Modifier** (`/organizations/<id>/edit`) :

- **Nom**, **identifiant court** (slug) et **description**.
- **Type** : association, club, liste, administration…
- **Organisation parente** (hiérarchie des organisations).

## Identité visuelle

- **Logo** : importez une image représentant l'organisation.
- **Couleurs** : couleurs principale, secondaire et sombre, utilisées dans l'interface.
- **Liens** : liens officiels (site, réseaux sociaux), avec un ordre d'affichage.
- **Galerie d'images** : images associées à l'organisation, réutilisables dans la
  description enrichie.

## Description enrichie

La description accepte une mise en forme légère (titres, gras, listes) et la mention de
membres pour présenter votre équipe.

> Ces réglages s'appliquent à **toute l'organisation** et sont publics. La liste ci-dessus
> indique où vous êtes administrateur. La **création** d'une organisation, elle, est
> réservée aux super-administrateurs ([[creer-une-organisation]]).
