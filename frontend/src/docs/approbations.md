# Approuver les événements

Les **super-administrateurs** (le ou la secrétaire du BDE) examinent les événements soumis à publication publique avant
qu'ils ne deviennent visibles de tous.

## Accéder aux demandes

Ouvrez [**Approbations**](/approval-requests) dans la section Administration de la barre
latérale. Un compteur indique le nombre d'événements **en attente**.

## Examiner un événement

Pour chaque demande, vous pouvez :

- **Approuver** : l'événement devient **public approuvé** et visible par tout le monde.
- **Refuser** : l'événement passe en **public refusé** avec un **message** ; son auteur
  peut le corriger puis le resoumettre.

Dans les deux cas, l'auteur reçoit un **e-mail** l'informant de la décision. Un outil de
détection des **événements qui se chevauchent** aide à repérer les conflits d'agenda.

## Auto-approbation

Les événements portant un **tag auto-approuvé** sont publiés **automatiquement**, sans
passer par cette file. Le statut auto-approuvé d'un tag se règle au niveau des tags
([[tags-organisation]]).
