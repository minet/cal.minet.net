# Gérer les tags d'une organisation

Les **tags** classent les événements par thème et permettent aux personnes intéressées de
s'y abonner. Leur gestion est réservée aux **administrateurs** de l'organisation.

## Créer et modifier des tags

1. Sur la page de l'organisation, ouvrez la gestion des **tags**
   (`/organizations/<id>/tags`).
2. **Créez** un tag (nom + couleur) ou **renommez / recolorez** un tag existant.

> La suppression d'un tag n'est pas proposée dans l'interface : préférez réutiliser les
> tags existants.

## Utilisation

Une fois créés, les tags peuvent être associés aux événements lors de leur création ou
modification. Les personnes peuvent s'abonner à un tag pour suivre ses événements
([[s-abonner]]).

## Auto-approbation

Un tag peut être marqué **auto-approuvé** : les événements publics portant ce tag sont
alors publiés **sans passer par la validation**. Ce réglage est réservé aux
**super-administrateurs** ([[approbations]]).

> La gestion des tags concerne **votre organisation**. La liste ci-dessus indique où vous
> êtes administrateur.
