# Mes notifications

Calend'INT peut vous envoyer des **notifications push** pour vous rappeler les événements
à venir.

## Activer les notifications

1. Autorisez les notifications pour le site lorsque votre navigateur le demande.
2. Sur mobile, installer l'application (ajout à l'écran d'accueil) améliore la fiabilité.

## Régler le délai de rappel

Dans votre profil, le **délai de notification** définit combien de temps avant le début
d'un événement vous êtes prévenu (par défaut **45 minutes**).

## Pour quels événements ?

Vous recevez un rappel pour un événement uniquement s'il est **public approuvé** et si
vous êtes **abonné** à son organisation ou à l'un de ses tags ([[s-abonner]]). Le rappel
est envoyé autour de votre délai configuré.

## Si vous ne recevez rien

- Vérifiez que les notifications ne sont pas bloquées dans votre navigateur ou votre
  système.
- Vérifiez votre abonnement à l'organisation ou au tag concerné.

> Ces réglages sont **personnels** et n'affectent que vous.
