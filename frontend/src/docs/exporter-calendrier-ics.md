# Exporter mon calendrier (ICS)

Calend'INT génère un lien **ICS** personnel qui reflète votre activité. En l'ajoutant à
votre application d'agenda, vos événements s'y synchronisent automatiquement.

## Récupérer votre lien

Ouvrez directement la fenêtre d'ajout au calendrier :
[Ajouter à mon calendrier](/profile/add_calendar). Vous pourrez y **copier votre lien
ICS** personnel.

Vous pouvez aussi y accéder depuis **Mon profil**, section « Calendrier personnel (ICS) »
([[mon-profil]]).

Ce lien contient une clé de sécurité propre à votre compte : **ne le partagez pas**.

## Ajouter le calendrier

- **Google Agenda** : Paramètres → *Ajouter un agenda* → *À partir d'une URL* → collez le
  lien.
- **Apple Calendrier** : Fichier → *Nouvel abonnement à un calendrier* → collez le lien.
- **Outlook** : *Ajouter un calendrier* → *S'abonner à partir du Web* → collez le lien.

## Ce que contient le calendrier

Le calendrier rassemble les événements :

- des organisations dont vous êtes **membre** ;
- des organisations et des **tags** auxquels vous êtes **abonné** ;
- des événements **privés** des groupes dont vous faites partie ;
- des événements auxquels vous avez **réagi** ([[reagir-evenements]]) ;
- des événements **à la une**.

L'historique remonte plus loin pour vos organisations (membres) que pour les simples
abonnements. La mise à jour se fait périodiquement, selon votre application d'agenda.
