# Partager un événement ou une organisation

Le bouton **Partager** crée un **lien court** (de la forme `cal.minet.net/s/xxxx`) facile à diffuser.
Le lien affiche un bel aperçu (titre, image, description) sur les réseaux et messageries.

## Depuis où partager

- La page d'un **événement** : bouton de partage.
- La page d'une **organisation** : bouton **Partager**.

## Types de liens

Selon le contexte, le lien peut déclencher différentes actions :

- **Voir** : ouvre la page de l'événement ou de l'organisation.
- **Compte à rebours** : ouvre l'écran de compte à rebours d'un événement.
- **Paiement** : ouvre directement la billetterie d'un événement.
- **S'abonner** : ouvre une page de confirmation. En confirmant, la personne s'abonne à
  l'organisation ou au tag ; pour un événement, elle y ajoute une réaction 👍 (ce qui
  l'ajoute à son calendrier).

## Qui peut créer un lien ?

- Partager une **organisation** ou un **tag** : il faut en être **membre**.
- Partager un **événement** : il faut pouvoir le **voir**.

> Un lien identique déjà existant est réutilisé plutôt que recréé.
