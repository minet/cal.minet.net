# Se connecter

Calend'INT n'utilise pas de mot de passe propre : la connexion se fait via le **compte
CAMPUS** (authentification du campus).

## Étapes

1. Sur la page de connexion, lancez la connexion **CAMPUS**.
2. Authentifiez-vous sur le portail du campus.
3. Vous êtes redirigé vers Calend'INT, désormais connecté.

## Création du compte

Lors de votre première connexion, votre compte est **créé automatiquement** à partir de
votre adresse e-mail et de votre nom fournis par CAMPUS. Aucune inscription séparée n'est
nécessaire.

## Durée de session

La session reste active environ **30 jours**. Au-delà, il suffit de se reconnecter via
CAMPUS.

> Un super-administrateur peut aussi vous **inviter** : vous recevez alors un e-mail vous
> invitant à vous connecter pour finaliser votre compte. Voir [[bienvenue]].
