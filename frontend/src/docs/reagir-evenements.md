# Réagir à un événement

Sur la page d'un événement (ou depuis le compte à rebours), vous pouvez ajouter une
**réaction** sous forme d'emoji.

## Comment réagir

1. Ouvrez un événement que vous pouvez voir.
2. Choisissez un emoji dans le sélecteur de réactions.

## Bon à savoir

- Vous n'avez **qu'une seule réaction** par événement : choisir un autre emoji remplace le
  précédent, recliquer sur le même le retire.
- Réagir à un événement l'**ajoute à votre calendrier** exporté : les événements auxquels
  vous avez réagi sont inclus dans votre export ICS ([[exporter-calendrier-ics]]).
- Les organisateurs de l'événement (membres et administrateurs) peuvent voir la liste des
  personnes ayant réagi.

> Vos réactions sont **personnelles**. Vous devez pouvoir voir l'événement pour y réagir.
