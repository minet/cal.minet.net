# Mettre des événements à la une

Les **super-administrateurs** peuvent mettre un événement **à la une**. Le réglage se fait
dans le formulaire de **modification de l'événement** ([[modifier-supprimer-evenement]]) :
un champ dédié n'apparaît que pour les super-administrateurs.

## Effets

Un événement à la une est mis en avant :

- en tête du fil **« À venir »** ;
- sur le **mur d'événements** ([[affichages-compte-a-rebours-mur]]) ;
- dans le calendrier exporté de **tout le monde** : les événements à la une sont inclus
  dans l'export ICS, même sans abonnement ([[exporter-calendrier-ics]]).

## Bon usage

La mise à la une est volontairement large dans sa portée : réservez-la aux événements
majeurs concernant l'ensemble du campus.

> Seuls les super-administrateurs peuvent régler la mise à la une.
