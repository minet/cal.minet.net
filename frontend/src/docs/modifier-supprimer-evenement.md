# Modifier ou supprimer un événement

Depuis la page d'un événement, un bouton **Modifier** apparaît si vous avez le droit de
l'éditer.

## Qui peut modifier ?

- Les **administrateurs** de l'organisation : tous les événements de l'organisation.
- Les **membres** de l'organisation : tous les événements, **sauf les événements privés
  dont ils ne sont pas l'auteur** (les privés ne sont éditables que par leur auteur et les
  administrateurs).
- Les membres et administrateurs des **organisations invitées** d'un événement
  co-organisé.
- Les **super-administrateurs** : tout.

## Limites

- Un événement **passé** (déjà terminé) ne peut plus être modifié, sauf par un
  super-administrateur.
- Repasser un événement public déjà traité en attente le **renvoie en validation**.

## Supprimer

Le même droit d'édition permet de **supprimer** un événement.
