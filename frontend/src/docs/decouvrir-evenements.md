# Découvrir les événements

Trois vues complémentaires permettent de parcourir les événements.

## Le fil « À venir »

Page d'accueil (icône journal dans l'accès rapide). Elle présente les prochains
événements sous forme de fil, en mettant en avant les événements **à la une**.

## Le calendrier

La page **Calendrier** affiche les événements dans une vue mensuelle / agenda, pratique
pour visualiser une période.

## Tous les événements

La page **Tous les événements** liste les événements avec **recherche** et **filtres**
(par organisation, par période). Vous pouvez aussi parcourir une organisation précise
depuis sa page pour voir ses événements à venir.

## Quels événements voyez-vous ?

- Les événements **publics approuvés** sont visibles par tout le monde, même sans être
  connecté.
- Les événements en **brouillon**, **en attente** ou **refusés** ne sont visibles que par
  les membres de l'organisation concernée (et les administrateurs).
- Les événements **privés** ne sont visibles que par leur auteur, les membres du groupe
  associé (ou tous les membres de l'organisation si aucun groupe n'est précisé) et les
  administrateurs.
